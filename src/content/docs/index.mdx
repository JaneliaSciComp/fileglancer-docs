## What is Fileglancer?

Fileglancer is an open-source web application for browsing, viewing, and sharing large scientific imaging data. It works directly with data where it already lives on your network file systems, so there is nothing to upload or copy. It embraces [next-generation file formats](https://www.nature.com/articles/s41592-021-01326-w) such as OME-Zarr, letting you inspect metadata, preview images, and open datasets in viewers like Neuroglancer, Avivator, and Fiji with a click.

Fileglancer was created at [Janelia Research Campus](https://www.janelia.org), where it serves as the shared data browser for the whole campus. It is built to be deployed anywhere: on your laptop, in your lab, or across your institution.

## Try it in one command

If you have [uv](https://docs.astral.sh/uv/) installed, you can run a personal Fileglancer server right now. Nothing else to install.

```bash
uvx fileglancer start
```

Your browser opens with your home directory ready to browse. The [Quick Start Guide](./getting-started/quick-start/) walks through this step by step, and explains how to run Fileglancer from source or deploy a shared server for your institution.

## Using Fileglancer at Janelia

Janelia researchers can use the shared campus deployment at [fileglancer.int.janelia.org](https://fileglancer.int.janelia.org) without installing anything. The [Using Fileglancer at Janelia](./getting-started/janelia/) guide covers logging in, finding your group's file shares, and the campus-specific details of sharing data.
