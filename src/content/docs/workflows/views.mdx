A View is a saved Neuroglancer scene: the datasets it shows, plus the layer colors, visibility, zoom level, and camera position. You build a View from datasets in the file browser, open it in a Neuroglancer viewer inside Fileglancer, and share it with a link. When you edit and save a View, everyone with its link sees the new version.

## What are Views?

- **Built from your files**: Pick datasets in the file browser. Fileglancer creates the Data Links and the Neuroglancer layers for you.
- **Opened in Fileglancer**: Views open in a Neuroglancer viewer embedded in Fileglancer.
- **Editable**: Change the View in the viewer, add or remove datasets, and save. The link stays the same.
- **Shareable**: Each View has a link that you can send to collaborators.

## Before you start

Views work with Zarr, OME-Zarr, and N5 datasets. You can add other folders to a View, but Neuroglancer can't load them as layers. Fileglancer lists them as sources only.

Each dataset in a View is served through a Data Link. If a dataset doesn't have one yet, Fileglancer creates it when you create the View. Unless you turned on automatic Data Links in your preferences, Fileglancer asks first. For more about Data Links, see [Creating Data Links](/workflows/data-links/).

## Create a View

You create a View in two stages. First you collect datasets in the **Layer Cart**, then you create the View from the cart.

### Step 1: Add datasets to the Layer Cart

The Layer Cart is a panel on the right side of the Browse page. To open it, click the cart icon (**View Layer Cart**) in the file browser toolbar.

Add datasets to the cart in any of these ways:

- **One folder**: Right-click a folder in the file list, or click the icon in its Actions column, and select **Add to cart** from the context menu.
- **Several folders**: Check the boxes next to the folders, then click **Add N to cart** in the selection bar that appears at the bottom of the screen.
- **The dataset you're viewing**: Under the image thumbnail of a Zarr or N5 dataset, click **Add to cart**.
- **From the cart panel**: Navigate to a dataset folder and click **Add current dataset**.

The cart keeps its contents until you create a View or clear it, so you can collect datasets from several folders and file shares.

### Step 2: Review the cart

Each dataset in the cart shows an icon that tells you whether it will load as a Neuroglancer layer. In the cart you can:

- **Pick channels**: Expand a multichannel OME-Zarr dataset and select channels to create a layer for each channel. To select every channel at once, check **All channels**. This is optional. If you don't select channels, the whole dataset becomes one layer.
- **Check dimensions**: A warning icon marks a dataset whose dimensions differ from the first dataset in the cart. The View takes its dimensions from the first dataset, so a mismatched dataset might not line up with the others. To see a dataset's full dimensions, expand it. To expand every dataset at once, click **Expand all**.
- **Remove a dataset**: Click the trash icon on the dataset's row.

### Step 3: Create the View

<Steps>
1. **Click "Create View"**<br/>
At the bottom of the Layer Cart.

2. **Name the View**<br/>
Replace the default name, "New View", with a name that describes the View.

3. **Confirm any prompts**<br/>
If Fileglancer needs to create Data Links and the automatic data link setting isn't enabled, the dialog asks you to confirm. The dialog will also show an informational warning if the cart has datasets with mismatched dimensions.

4. **Click "Create"**<br/>
The View opens in the Neuroglancer viewer, and the cart is emptied.
</Steps>

:::note
If a View has more than four layers, the layers after the fourth start archived, so that the View loads quickly. To show an archived channel of a multichannel dataset, check it in the **Sources** tab of the viewer sidebar (see [Show, hide, or remove datasets and channels](#show-hide-or-remove-datasets-and-channels)). To show any other archived layer, open it from the layer list in Neuroglancer.
:::

## Open a View

Click **Views** in the top navigation bar to see the Views you own. To open one, select **Open View** from the row's actions menu.

You can also open a View from the **Properties** panel on the Browse page. When a dataset is part of any of your Views, the panel lists them under **Appears in N Views**. Click a name to open the View.

The viewer toolbar has these buttons:

- **Add data**: Opens the sidebar on the **Add data** tab, for adding datasets. Only the View's owner sees this button.
- **View and edit data sources** (info icon): Opens the sidebar on the **Sources** tab, for showing, hiding, and removing datasets and channels. Only the View's owner sees this button.
- **Copy link to share**: Copies the View's link to your clipboard.
- **Download JSON**: Downloads the View's Neuroglancer state as a JSON file.
- **Open in Neuroglancer**: Opens the View in a standalone Neuroglancer tab. You can configure whether this is the internal Janelia Neuroglancer deployment or the external appspot deployment on the **Preferences** page.
- **Fullscreen**: Expands the viewer to fill your screen.

To return to your list of Views, click **Views** in the toolbar.

## Edit a View

Only the owner of a View can edit it. Other people who open the View can explore it, but they can't save changes.

### Change and save the View

<Steps>
1. **Make changes in Neuroglancer**<br/>
Adjust the View in the viewer: change colors or contrast, show or hide layers, move the camera, or change the layout. When you have unsaved changes, the **Save** button in the toolbar becomes available.

2. **Click "Save"**<br/>
Saving updates the View for everyone with its link. To go back to the last saved version instead, click **Discard**.
</Steps>

If you try to leave the viewer with unsaved changes, Fileglancer asks whether to **Save and continue**, **Continue without saving**, or **Cancel**. Copying the link, downloading the JSON, and opening the View in Neuroglancer ask the same question, because they use the saved View.

:::caution
The browser's back and forward buttons leave the viewer without asking. Save your changes before you use them.
:::

### Rename the View

Click the pencil icon next to the View's name in the toolbar, type the new name, and press Enter. You can also select **Rename** from the row's actions menu on the Views page.

### Add datasets

<Steps>
1. **Click "Add data"**<br/>
In the viewer toolbar. A sidebar opens on the right side of the viewer.

2. **Find your datasets**<br/>
On the **Add data** tab, browse to the folder that holds your datasets, or type or paste a path in the path field.

3. **Check the datasets to add**<br/>
Fileglancer checks each dataset and warns you about any that can't load as a Neuroglancer layer, or whose dimensions differ from the View's first layer.

4. **Click "Add N to this View"**<br/>
If Fileglancer needs to create Data Links, confirm the prompt. The new layers appear in the viewer.

5. **Click "Save"**<br/>
Added datasets aren't part of the View until you save.
</Steps>

### Show, hide, or remove datasets and channels

To open the **Sources** tab, click the info icon (**View and edit data sources**) in the viewer toolbar. You can also switch to it from the **Add data** tab of the sidebar.

To remove a dataset in the viewer, click the remove icon next to the dataset on the **Sources** tab. Then click **Save**.

To show or hide a channel of a multichannel dataset, expand the dataset on the **Sources** tab. The list includes every channel in the dataset, including channels that aren't in the View yet. Check a channel to show it, or to add it to the View. Uncheck a channel to hide it; checking it again brings it back with its settings. Then click **Save**. To expand every dataset at once, click **Expand all**.

To remove datasets from the Views page:

<Steps>
1. **Select "Remove datasets"**<br/>
From the actions menu on the View's row.

2. **Check the datasets to remove**<br/>
Removing a dataset removes all of its layers from the View. The data itself isn't affected.

3. **Click "Remove"**<br/>
The change takes effect right away.
</Steps>

### Editing isn't available

If the viewer toolbar shows "Editing isn't available with this Neuroglancer deployment", Fileglancer can't read the viewer's state, so you can view the View but not edit it. This happens when your Fileglancer deployment serves Neuroglancer from a different site. Contact your Fileglancer administrator.

## Share a View

<Steps>
1. **Copy the View's link**<br/>
In the viewer, click **Copy link to share**. On the Views page, you can also select **Copy View link to share** from the row's actions menu.

2. **Send the link**<br/>
Collaborators who open the link see the View in the Fileglancer viewer. They need to sign in to Fileglancer.
</Steps>

To share a View with someone who doesn't use Fileglancer, download its JSON state with **Download JSON**, or open it with **Open in Neuroglancer** and share that Neuroglancer URL.

:::note[Sharing with external collaborators]
Anyone with access to the Janelia network can load the data in a View. If your image data is located in a `data_external` folder on a Janelia file share, it can also be loaded outside the Janelia network. Files in `data_external` folders are automatically made public on [s3.janelia.org](https://s3.janelia.org). In addition, ensure your preference for the Neuroglancer viewer is set to the external appspot deployment on the **Preferences** page before you copy the Neuroglancer link.

:::

## Manage your Views

The Views page lists the Views you own. The table shows:

- **Name**: The name of the View.
- **Datasets**: The number of datasets in the View.
- **Sources**: The path of each dataset in the View. A warning icon marks a dataset that can't load as a Neuroglancer layer, or whose Data Link was deleted.
- **Updated**: When the View was last saved.
- **Actions**: Open View, Copy View link to share, Download JSON state, Rename, Remove datasets, and Delete.

To delete a View, select **Delete** from the actions menu and confirm. The View's link stops working. Its Data Links and data aren't affected.

## Fix broken sources

A View loads each dataset through a Data Link. If you delete a Data Link that a View uses, that dataset can't load in the View. Fileglancer warns you before you delete a Data Link that any of your Views use.

To fix a broken source, do one of the following:

- **Create a new Data Link for the dataset**: Fileglancer relinks your broken Views on that dataset automatically and shows "Relinked N broken View(s)".
- **Relink from the Views page**: In the **Sources** column, click **Relink** next to the broken source. If you already have another Data Link for the dataset, Fileglancer uses it. Otherwise, it offers to create one.
- **Relink from the viewer**: When you open a View with broken sources, a banner lists them with a **Relink** button. Save or discard any unsaved changes first.

If Fileglancer can't relink a source, you can remove it from the View, or recreate the View.

## Troubleshooting

### A View shows "View not found"

The View was deleted, or the link was copied incorrectly. Ask the View's owner for a new link.

### A dataset doesn't appear as a layer

- Check the dataset's icon in the Layer Cart or the **Sources** list. Plain folders and other formats that Neuroglancer can't read are listed as sources only.
- If the View has more than four layers, the layer might be archived. For a channel of a multichannel dataset, check it in the **Sources** tab of the viewer sidebar. For any other layer, look for it in the Neuroglancer layer list.
- If the source has a warning icon in the **Sources** column of the Views page, its Data Link was deleted. See [Fix broken sources](#fix-broken-sources).

### Layers don't line up

The View takes its dimensions from its first dataset. Datasets with different dimensions or units might not line up. Check for the dimension warning in the Layer Cart before you create or add to a View, and expand a dataset to see its full dimensions. In an open View, expand a dataset on the **Sources** tab of the viewer sidebar.

### Collaborators can't load the data

- Confirm that they're on the Janelia network, or that the data is in a `data_external` folder.
- Check the **Sources** column on the Views page for broken sources.

## Neuroglancer Short Links

Views replace Neuroglancer Short Links. Existing short links still work, and the old **NG Links** page now opens the Views page.

## Best practices

- **Use descriptive names**: A clear name helps you and your collaborators find the View later.
- **Check dimensions first**: Put the dataset whose dimensions you want the View to use first in the cart.
- **Save before you share**: Collaborators see the last saved version of the View.
- **Keep Data Links**: Views depend on Data Links. Before you delete a Data Link, check which Views use it.
- **Clean up old Views**: Delete Views you no longer need from the Views page.
