This quick start guide will help you get up and running with Fileglancer in just a few minutes. We'll cover the essential steps to navigate the interface, access your data, and view OME-Zarr images.

## Access Fileglancer

1. **Connect to Janelia network**: Ensure you're on the Janelia internal network or using the VPN
2. **Open your browser**: Navigate to [fileglancer.int.janelia.org](https://fileglancer.int.janelia.org)
3. **Authenticate**: Log in via Okta with your Janelia credentials

## View OME-Zarr data

We'll use an example data set to get familiar with the interface. 
<Steps>
1. **Copy path**<br/>
Copy this path into your clipboard:<br/>
    ```/nrs/opendata/ome-zarr-examples/fused-timeseries.zarr```

2. **Navigate**<br/> 
Click the "Navigate to path" button in the toolbar, paste the path and click "Go".

3. **See metadata**<br/> 
Since this is an OME-Zarr image, you can view all of its metadata along with a thumbnail image.

3. **View image**<br/> 
Click on the "Neuroglancer View" button under the thumbnail.

4. **Create the View**<br/> 
Viewing an image requires a data link. In the dialog that appears, name the View, confirm the data link, and click "Create".

5. **Visualize**<br/> 
Your image will open as a View in Fileglancer's embedded Neuroglancer viewer.
</Steps>

## Create and share a View

A View saves a Neuroglancer scene: the datasets it shows, plus the layer colors, visibility, zoom level, and camera position. Collaborators who open the View's link see exactly what you configured.

<Steps>
1. **Add datasets to the Layer Cart**<br/>
In the file browser, right-click any directory and select **Add to cart**. For Zarr, OME-Zarr, and N5 data, you can also click the "Add to Cart" button in the metadata panel for the dataset. To add several folders at once, check their boxes in the file browser and click **Add N to cart** in the selection bar that appears at the bottom of the screen.

2. **Create the View**<br/>
In the Layer Cart panel, click **Create View**, name the View, and click **Create**. If Fileglancer needs to create Data Links for your datasets and automatic Data Links aren't enabled, it asks you to confirm first. The View opens in the Neuroglancer viewer.

3. **Configure the View**<br/>
Adjust the layers, colors, and camera position exactly how you want collaborators to see them, then click **Save** in the viewer toolbar.

4. **Share the link**<br/>
Click **Copy link to share** in the viewer toolbar and send the link to your collaborators.
</Steps>

:::tip[Why use Views?]
A View's link stays the same when you edit and save the View, so collaborators always see your latest version. You can also add datasets to a View or remove them later, right from the viewer.
:::

## Essential Tips

### Navigation Shortcuts
- **Breadcrumbs**: Use the breadcrumb trail to quickly move up directory levels.
- **Copy path**: Hover over the breadcrumbs to reveal a copy button that copies the current path into your clipboard.
- **Paste onto page**: Power users can take advantage of a special hidden feature: if you have a path in your clipboard, simply click anywhere in the file browser and paste using your usual keyboard shortcut. The "Navigate" dialog will come up automatically, prefilled with your path.

### Data Link Management
- **View all data links**: Visit the *Data Links* page to see all your current data links
- **Enable automatic data links**: When creating data links, you can choose to enable automatic link creation for future similar actions

### Getting Help
- **Built-in help**: Look for help icons and tooltips throughout the interface
- **Technical support**: Use the integrated help desk system for complex issues

## Common First Tasks

### Scenario 1: Sharing Lab Data with an Internal Collaborator
1. Navigate to your lab's shared data directory
2. Find the specific dataset you want to share
3. Create a data link using the Properties Panel
4. Send the data link to your collaborator

### Scenario 2: Collaborating on Image Analysis
1. Add your OME-Zarr datasets to the Layer Cart
2. Create a View from the Layer Cart
3. Configure the viewer to highlight specific features or regions, then save the View
4. Share the View's link with collaborators so they see exactly what you configured

### Scenario 3: Organizing Your Workflow
1. Use search to find all your project directories
2. Save frequently-accessed folders as favorites
3. Create data links for datasets you reference often
4. Set up automatic data link creation for common sharing patterns
