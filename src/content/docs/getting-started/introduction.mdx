## Welcome to Fileglancer

Fileglancer is a web-based file browser and data sharing platform for researchers who work with large scientific imaging data. It connects directly to the file systems where your data already lives, so you can browse, inspect, view, and share datasets from a browser without moving files or learning command-line tools.

Fileglancer is open source and was created at Janelia Research Campus, where a shared deployment serves the entire campus. It can also run as a personal server on your own computer, or be deployed for your lab or institution.

## Why Fileglancer?

Fileglancer addresses common challenges researchers face when working with large datasets:

- **No data movement**: Browse and share data directly from existing network file systems. Terabyte-scale datasets never need to be copied or uploaded.
- **Simple sharing**: Create Data Links that give collaborators browser access to a dataset, and Views that capture exactly how you configured a visualization.
- **Modern format support**: Inspect metadata and thumbnails for Zarr, OME-Zarr, and N5 datasets, and open them in viewers such as Neuroglancer, Avivator, and Fiji with one click.
- **Compute where the data is**: Run command-line tools and services on a compute cluster from the browser, with job status tracked in Fileglancer.
- **Familiar interface**: A clean web UI means no command-line experience is needed for everyday file management.

## How Fileglancer is deployed

Fileglancer runs in two modes, and the documentation covers both:

- **Personal server**: Start Fileglancer on your own computer with a single command to browse and view your own data. Links you create work only while your server is running.
- **Shared deployment**: An administrator runs Fileglancer on a server at your institution. Users log in with their institutional credentials, see the files they have permission to read, and can share links that keep working.
